# Electric Vehicle Price Prediction and Classification 🚗⚡

##  Project Overview
This project analyzes the **Electric Vehicle Market and Pricing Dataset (2026)** to understand the factors influencing EV prices and to build machine learning models for:

- Predicting EV prices (Regression)
- Classifying EVs into high-price and low-price categories (Classification)

---

##  Dataset Information
- **Dataset Name:** Electric Vehicle Market and Pricing Dataset 2026  
- **Source:** Kaggle  
- **Link:** https://www.kaggle.com/datasets/patelris/electric-vehicle-market-and-pricing-dataset-2026  

The dataset includes features such as:
- Price  
- Range  
- Battery Capacity  
- Manufacturer  
- Other vehicle specifications  

---

##  Objectives
- Analyze EV pricing trends  
- Identify key factors affecting price  
- Build regression models to predict price  
- Build classification models to categorize vehicles  

---

##  Research Questions
1. Can machine learning models accurately predict EV prices?  
2. Which features most influence EV pricing?  
3. How does battery capacity affect price?  
4. What is the relationship between range and price?  
5. Can EVs be classified into high and low price categories?  
6. Which regression model performs best?  
7. Which classification model performs best?

- Accuracy  
- Precision  
- Recall

## Results
- Machine learning models successfully predicted EV prices  
- Battery capacity and range were key influencing factors  
- XGBoost and Random Forest performed best in most cases  
- Classification models effectively categorized EVs into price groups
